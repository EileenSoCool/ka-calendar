# 微博 Cookie 提供教程

每次执行月历抓取前，请按以下 5 步提供一次有效的 **SUB 值**（抓取只需要这一项）。该方式的优点是：全程在本机浏览器内完成，无需提供账号密码；SUB 用后即弃，风险相对可控。

## 5 步拿到 SUB

1. **登录网页版微博**
   浏览器打开 https://weibo.com 并登录你自己的账号（任何账号都行，不要求是大号）。

2. **随便点开一个微博界面**
   比如：https://weibo.com 主页向下滚两下，让页面自动加载内容（会触发后台数据请求，这步是关键——必须让后台发出 API 请求）。

3. **按 F12 打开开发者工具**
   切到 **Network**（网络）标签页。

4. **再滚动页面一下**，Network 列表会刷出很多条请求。找一条像 `mymblog`、`groupstimeline`、`allGroups`、`profile/info` 这类 `xhr/fetch` 请求，点它。

5. **复制 Cookie 里的 SUB 值发我**
   - 右侧详情面板选 **Headers**（标头）
   - 往下滚到 **Request Headers**（请求标头）
   - 找 `Cookie:` 那一整行
   - 里面找 `SUB=` 开头到 `;` 之前的那段值（一长串，约 100+ 字符）
   - 把那一串贴给我就行，**別委其它字段**。

> 找不到的话截张 Network 面板图给我也行，不过我只需要 `SUB=` 后面的值。

## 安全说明

- SUB 这里**只用于读微博**，不做任何写操作。
- 我使用完立刻删除，**不会写入持久文件/记忆/数据库**。
- 你要立刻让它失效：微博 App/网页 → 设置 → 账号安全 → 退出登录所有设备（再本人登录一次就好）。发完后请作废一次。

## 我需要你做的（一句话版本）

> 打开 weibo.com 登录 → 主页往下滑两下 → F12 → Network → 点任意一条 mymblog/timeline 请求 → Headers → Request Headers → Cookie → 复制 `SUB=` 后面的值给我。
